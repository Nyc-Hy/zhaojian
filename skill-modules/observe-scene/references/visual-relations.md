# 可见关系参考

- `overlap`：两个元素在画面中发生遮挡。
- `separation`：两个元素之间存在可见间隔。
- `continuation`：轮廓或方向在元素之间延续。
- `repetition`：形状、颜色或间隔形成重复。
- `directional_contrast`：主要方向彼此冲突。
- `scale_contrast`：元素之间存在可见尺度差。
- `tonal_contrast`：明暗差异组织注意。
- `color_contrast`：色相或冷暖差异组织注意。
- `frame_tension`：元素与画框边缘发生可见关系。
- `depth_layering`：前、中、后景形成层叠。

关系必须同时包含具体元素名称、可见证据和置信度。
