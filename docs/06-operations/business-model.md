# 商业模式与保本假设

状态：假设文件，需用真实数据更新。目标不是一开始追求规模，而是确保娱乐性产品不会因每次 AI 调用持续亏损。

## 1. 推荐模式

采用“本地能力免费 + 云端分析按量”的轻量模式：

- **免费层**：器材档案、参数计算器、拍摄笔记、少量首次分析。
- **次数包**：适合偶尔外拍用户，购买后不过度催促使用。
- **短期通行证**：例如一次旅行或一个周末内有较高额度，但仍设公平使用上限。
- **支持者版本**：可提供主题、导出和更多本地功能，不承诺永久免费云端分析。

暂不建议：

- 广告驱动：会打断现场体验，也与安静、克制的产品气质冲突。
- 终身买断且无限 AI：未来模型成本不可控。
- 纯订阅作为唯一入口：低频摄影用户很难持续感知价值。
- 出售图片或用户画像：与隐私承诺冲突。

## 2. 保本模型

每月贡献毛利可用下式估算：

`贡献毛利 = 实收收入 - 商店抽成 - 模型调用 - 云资源 - 支付退款 - 可变客服成本`

`保本付费用户数 = 每月固定成本 ÷ 单个付费用户月贡献毛利`

必须记录的真实数据：

- 每次分析的图像输入量、文本输入/输出量和模型费用。
- 成功、失败、重试和免费补偿次数。
- 每名免费/付费用户的月调用次数分布。

当前 `qwen3.7-plus` 费用估算使用 2026-07-21 核对的中国内地、单次输入不超过 256K、非思考模式目录价：输入 ¥2/百万 Token、输出 ¥8/百万 Token，计价版本为 `aliyun-cn-list-0-256k-2026-07-21`。限时优惠、缓存折扣、免费额度和供应商最终账单不计入该估算；调价后必须新增计价版本，不能改写历史任务。
- 各渠道实收、平台抽成、退款和税费。
- 服务器、对象存储、短信/邮件、监控和客服成本。

不要只用模型官网的“最低价格”计算；应使用真实请求的 P50、P90 成本，并为供应商调价与汇率留出缓冲。

## 3. 建议的验证顺序

1. 先给种子用户固定免费额度，测量他们是否真的会第二次使用。
2. 当有人达到额度后，询问其更愿意买次数还是买短期通行证。
3. 用商店沙盒验证购买流程，但在价值验证前不急于公开收费。
4. 只有当单次贡献毛利为正，才扩大免费获客。

## 4. 定价原则

- 价格和额度应与真实模型成本联动，本文不预设永久价格。
- 失败、超时或服务端拒绝不得消耗用户权益；若先扣除必须自动返还。
- 每次分析前清楚显示是否消耗额度。
- 不通过虚假的“构图评分”、倒计时或羞辱式文案制造付费焦虑。
- 价格页面说明 AI 只是建议，不能保证作品获奖或商业结果。

## 5. 关键业务指标

早期只看少数能改变决策的指标：

- 完成首次完整分析的用户比例。
- 7 天内再次用于另一个场景的比例。
- 用户最终采用某个方案并实际拍摄的比例。
- 每次成功建议的完全成本。
- 达到免费额度后的自然付费意愿。
- “太泛、太慢、太像命令、参数不可信”四类负反馈占比。

应用商店计划、抽成和中国区规则可能变化，上线前应重新核对官方页面，而不是把当前假设写死在代码中。
