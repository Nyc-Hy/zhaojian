# 中国境内发布与合规检查

本文件是产品与工程检查清单，不构成法律意见。正式公开运营、收费或处理大量用户图片前，应由熟悉中国数据与移动应用规则的专业人士复核。

## 1. 开发者主体与商店账户

- 确定以个人还是组织主体发布；两者的展示名称、材料和责任不同。
- iOS 公开分发通常需要加入 Apple Developer Program，并按官方当期标准支付年费。
- 组织主体通常还需要能够验证法人实体及 D‑U‑N‑S 信息。
- 确认应用名称“照见”在目标类别中的商标、公司名称、域名和应用商店占用；当前检索不等于商标清查。
- Android 若进入国内应用商店，逐家核对实名、软著、备案、隐私和 SDK 清单要求。

参考：

- [Apple Developer Program 注册说明](https://developer.apple.com/cn/programs/enroll/)
- [App Store Connect 应用信息说明](https://developer.apple.com/cn/help/app-store-connect/reference/app-information/app-information/)

## 2. 备案与网络服务

- 若应用在中国境内提供互联网信息服务，确认是否需要履行移动互联网应用程序备案。
- 使用中国境内服务器、域名或网站时，分别核对 ICP 备案、公安备案及云服务商要求。
- 在 App Store Connect 中准备并填写适用的备案信息。
- 服务端、隐私政策网页、客服网页和回调域名应使用可长期维护的正式域名。

参考：[工业和信息化部关于开展移动互联网应用程序备案工作的通知](https://www.gov.cn/zhengce/zhengceku/202308/content_6897341.htm?type=mobile-internet)

## 3. 个人信息与图片

参考图片可能包含人脸、车牌、住所、地理线索和设备元数据。默认采用数据最小化：

- 只申请当前功能所需的相机或相册权限，并在系统权限文案前解释用途。
- 默认去除不需要的 EXIF 和精确位置。
- 明确说明图片是否上传、传给哪类模型服务、保留多久、是否用于训练。
- 默认分析后删除服务端临时原图；若产品需要云端保存，必须让用户单独选择。
- 提供隐私政策、个人信息收集清单、第三方 SDK 清单、注销/删除和投诉渠道。
- 对未成年人使用、他人入镜、跨境传输和敏感个人信息另做评估。
- 不把拒绝非必要权限作为使用本地功能的前提。

参考：[App Store Connect 管理 App 隐私](https://developer.apple.com/cn/help/app-store-connect/manage-app-information/manage-app-privacy/)

## 4. AI 服务与生成内容

- 与模型供应商确认图片和提示词的存储区域、训练政策、内容审核、日志保留和分包商。
- 在界面中标识建议由 AI 辅助生成，并提供结果反馈或投诉入口。
- 对面向公众的生成式服务是否涉及算法备案、生成式人工智能服务管理要求及内容标识要求进行专项法律评估。
- 不让模型识别无关人员身份、评价个人属性或从画面推断敏感信息。
- 保留模型版本、提示词版本和安全事件记录，但不保留不必要的原图。

## 5. 商店审核与付费

- 摄像头、相册、网络和语音权限用途必须与实际功能一致。
- 若销售应用内数字次数、通行证或订阅，按目标商店当期规则接入应用内购买。
- 准备恢复购买、退款、失败返还、价格展示和客服流程。
- 商店截图和描述不得声称 AI 一定能生成“专业大片”或保证效果。
- 若包含账户，提供应用内账户删除入口，并验证服务端同步删除。

## 6. 上线前需取得的证据

- [ ] 发布主体与签约主体一致。
- [ ] 名称与标识已做目标市场检索。
- [ ] 备案要求已由专业人士或主管渠道确认。
- [ ] 隐私政策与真实数据流逐字段核对。
- [ ] 模型供应商和所有第三方 SDK 已进入清单。
- [ ] 原图、日志、备份和删除流程经过实测。
- [ ] AI 内容标识、反馈和安全处置要求已确认。
- [ ] 支付、税务、发票和退款责任已确认。
- [ ] 商店后台的隐私标签与应用行为一致。
