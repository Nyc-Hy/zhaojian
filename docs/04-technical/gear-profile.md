# 器材档案

正式契约见：[`schemas/gear-profile.schema.json`](../../schemas/gear-profile.schema.json)。

## 设计目标

- 不依赖全量商业器材数据库才能使用。
- 既支持“品牌 + 型号”检索，也支持通用手动录入。
- 器材能力服务于视角与参数计算，不成为器材消费推荐工具。

## 数据来源与可信度

- 内置目录中的“型号名称”和“技术规格”分开记录。
- 只有逐项对照厂商官方规格页并记录来源与核验日期的字段，才能自动带入参数引擎。
- 仅有型号名称的条目只用于模糊搜索；用户仍需确认传感器规格与高级参数。
- 防抖档数是厂商在指定镜头与测试条件下的标称值。安全快门规则最多保守折算 3 档，且不用于补偿主体运动。
- Auto ISO 上限属于用户画质偏好，不以机身可设置的最高 ISO 自动替代。
- 无来源、互相矛盾或依赖固件与拍摄模式的字段保持未知，并向用户显示条件说明。

## 相机字段

- 厂商和型号。
- 传感器宽高。
- 裁切系数。
- 基础 ISO 与 ISO 范围。
- 最快和最长快门。
- 机身防抖档数，可未知。
- 用户自定义备注。

## 镜头字段

- 厂商和型号。
- 定焦或变焦。
- 最短和最长实际焦段。
- 广角端与长焦端最大光圈。
- 最小光圈。
- 镜头防抖档数，可未知。
- 最近对焦距离，可未知。

## 附件字段

- 三脚架。
- 独脚架。
- 偏振镜。
- ND 镜及档位。
- 快门线或远程释放。

## 用户偏好

- 自动 ISO 上限。
- 是否拍 RAW。
- 手持稳定偏好：保守、正常、经过校准。
- 是否接受较高 ISO。
- 默认以画质、便利还是运动表达优先。

## 焦段可行性

模型只给出等效视角提示。器材服务执行：

1. 根据裁切系数换算为实际焦段。
2. 与所有已配置镜头范围求交集。
3. 给出可实现镜头和焦段。
4. 无交集时选择最接近边界，并说明画面会更宽或更窄。

## 首次视角校准（后续）

- 用户将真实相机设为已知焦段。
- 手机与相机尽量保持同一位置和方向。
- 调整手机叠加框使其与相机画面一致。
- 保存手机、相机、画面比例和焦段的校准关系。

校准只改善取景框近似，不用于宣称光学模拟准确。
