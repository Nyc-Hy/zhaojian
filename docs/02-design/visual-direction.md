# 视觉方向

## 关键词

- 安静
- 留白
- 克制
- 可信
- 有呼吸感
- 像摄影笔记，而不是相机仪表盘

## 视觉原则

### 让照片成为主角

界面颜色和装饰不与参考图竞争。分析页使用中性背景，根据照片亮度自动选择深浅模式。

### 技术信息延后出现

光圈、快门和 ISO 使用等宽数字或紧凑标签，但只在“怎么拍”页面出现。

### 不使用分数式视觉

避免：

- 环形得分仪表。
- 红黄绿构图质量灯。
- 进度条式审美评分。
- 主体检测框常驻。

### 轻量的取景示意

半透明裁切框只表示视角可能，不模拟虚假景深、镜头压缩或光学效果。

## 初步色彩

- 背景：接近炭黑或温暖灰白。
- 主文字：高对比中性色。
- 辅助色：低饱和苔绿色或暖金色，只用于可操作元素。
- 风险提示：避免高刺激红色，使用明确文字说明。

正式颜色值在视觉原型阶段确定，不在产品定义阶段过早锁定。

## 字体与排版

- 中文优先使用系统字体，保证小字号可读性与跨平台一致性。
- 标题短而有呼吸，正文行宽控制在易读范围。
- 数字参数需要对齐，避免小数点和单位跳动。
- 照片说明使用自然段，不堆叠专业术语标签。

## 动效

- 页面进入使用轻微淡入，不制造“AI 扫描”戏剧效果。
- 等待分析时显示过程文案，如“正在辨认画面关系”，不伪造精确进度。
- 切换不同观看方向时保持参考图位置稳定，便于比较取舍。
