# 项目简报

## 名称

- 中文名：照见
- 英文/项目代号：Zhaojian
- 副标题：摄影观看与技术随行助手
- 标语：先看见，再拍下。

## 一句话定义

当用户被一个场景吸引，却不确定怎样继续观看和实现时，照见提供几种不同的表达可能，并结合用户真实拥有的相机与镜头，将选中的方向翻译为可尝试的焦段和参数起点。

## 要解决的问题

摄影者常见的困难不是没有相机，也不是不知道三分法，而是：

- 感觉眼前值得拍，却说不清什么吸引了自己。
- 看到复杂场景，不知道保留什么、舍弃什么。
- 知道想表达的感觉，却不知道应该选择哪个焦段。
- 拥有相机和镜头，却难以把创作意图转换为光圈、快门和 ISO 的起点。
- 现有摄影工具偏参数、滤镜或审美打分，缺少对“观看过程”的尊重。

## 核心价值

1. 帮助用户辨认自己的注意力与感受。
2. 提供不同而非同义改写的观看可能。
3. 解释选择带来的视觉效果，不宣布审美裁决。
4. 使用用户真实器材，将表达变成可行的拍摄方案。
5. 通过摄影笔记保留“为什么这样拍”，帮助用户形成个人语言。

## 产品不是

- 自动寻找全世界最佳机位的导航器。
- 对照片进行统一审美评分的裁判。
- 用箭头命令用户站到算法指定位置的教练。
- 自动接管所有相机品牌的遥控器。
- 依靠精确参数幻觉制造专业感的聊天机器人。

## 第一阶段成功标准

- 用户能在 3 分钟内完成一次“参考图 → 表达 → 建议 → 参数 → 笔记”流程。
- 至少 60% 的测试用户认为建议帮助其看见了原本没有意识到的可能。
- 同一场景的建议在表达目标上具有明显差异，而非构图术语堆砌。
- 参数建议始终说明假设、范围和调整方法，不伪装成准确测光结果。
- 至少 80% 的测试用户能理解 AI 建议可以被修改或忽略。
