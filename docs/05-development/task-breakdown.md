## 当前工程基线

以下命令必须在不配置模型密钥、也不访问外部模型的条件下通过：

```bash
npm run verify
```

它依次验证 Schema、前端与规则单元测试、ASP.NET Core 集成测试、方向最低质量门禁、Web 构建和 .NET Release 发布。GitHub Actions 使用同一命令，避免本地与持续集成采用两套完成标准。
